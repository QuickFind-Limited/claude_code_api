# Legacy Workspace

The files in this directory are retained for historical reference only. They include:

- `scripts/`: one-off automation and exploratory scripts unrelated to the current API surface.
- `docs/`: archived documentation and reports.
- `data/`: datasets and JSON/CSV artifacts generated during previous analyses.
- `server/`: archived FastAPI routers kept for reference.
- `tests/`: manual or deprecated integration tests.
- `demos/`: experimental frontends and agents.
- `logs/`: archived log files.

These paths are excluded from linting and pre-commit checks.
